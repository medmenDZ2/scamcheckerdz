SCAMCHECK settings

Backend

SCAMCHECK needs an API that implements POST /v1/check and GET /v1/health. Point the extension at your own backend below.

QR code checker (paid feature)

Checking QR code destinations includes a 30-day free trial, then $2.99/month. Everything else in SCAMCHECK stays free.

Automatic checks

This sends the page's URL to your backend as you browse. Full-content checks (page text, forms, links) only ever happen when you click "Full check" or paste something in — never automatically.

Privacy

This extension does not collect or store anything itself. Whatever you check is sent directly to the backend URL you configured above, and how it's handled from there is up to that backend. Nothing is sent anywhere until you set an API URL.
